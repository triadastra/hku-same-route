What each block is for, from Kennedy Town to Sai Ying Pun

Every place on the map we built for the simulation, grouped by function and counted per block. A block here is a hexagon 104 m across, a little under one hectare. Darker blocks hold more places of the chosen function.

        Each small map uses its own scale, so compare where a function concentrates, not how many places it has. Select one to show it on the large map.

        Places are points from OpenStreetMap, so a tower with a hundred flats counts once, the same as a noodle shop. Only buildings that carry a name are on the map. Blocks are a regular grid laid over the footpaths, not the street blocks themselves. Map data © OpenStreetMap contributors, ODbL.
